# Enterprise Cloud Infrastructure & Observability Platform

An enterprise-style engineering project using Microsoft Azure and open-source DevOps tools.

## Project Objectives

- Azure cloud infrastructure
- Terraform Infrastructure as Code
- Reusable Terraform modules
- DEV, TEST, QA, STAGING and PROD environments
- Git and GitHub
- GitHub Actions CI/CD
- Linux administration and Bash
- Docker and Kubernetes
- Prometheus metrics collection
- Grafana dashboards
- Alertmanager notifications
- Loki centralized logging
- Security and access control
- Incident investigation and troubleshooting
- Cloud cost management

## Intended Architecture

Developer -> GitHub -> Pull Request -> CI/CD Pipeline
-> Terraform Validation -> Azure Infrastructure
-> Application Deployment -> Prometheus -> Grafana
-> Alertmanager -> Incident Response

## Technology Stack

| Area | Technology |
|---|---|
| Cloud | Microsoft Azure |

- Infrastructure validation and review
